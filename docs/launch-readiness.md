# Academia 正式上市闸门

## 当前结论

Cloudflare 版本适合公开功能预览和受控种子测试，不适合在中国内地正式收费运营。正式上市必须同时跨过主体与许可、国内基础设施、账户安全、支付、生成式 AI 合规、个人信息保护和运营保障七类闸门。

## 需要创始人推进

### 主体、定位与许可

- 确定正式经营主体，准备营业执照、法人和对公银行账户。
- 与熟悉互联网、教育和生成式 AI 的中国律师确认产品属于成人非学历知识服务、职业培训还是教育服务。
- 明确 Academia 不颁发国家承认的学历或学位；“大学、学院、学分、毕业”等命名及宣传边界需完成法律审查。
- 付费提供课程信息可能属于经营性互联网信息服务；向主体所在地通信管理局或专业代办确认需要 ICP 许可证还是其他增值电信许可。
- 如被认定为教育类互联网信息服务，确认是否需要教育主管部门前置审批。

### 域名与备案

- 选择并购买正式主域名，建议使用企业主体持有的 `.com` 或 `.cn`。
- 域名完成企业实名认证，持有人信息与备案主体保持一致。
- 购买阿里云中国内地可备案资源，提交 ICP 备案；正式收费前确认经营许可范围。
- 上线后按要求完成公安联网备案，并在首页展示备案和许可编号。

### 邮箱与通知

- 确定发件域名，例如 `mail.example.com`，以及“学籍通知”和“安全通知”的发件人名称。
- 开通阿里云 DirectMail，完成 SPF、DKIM、DMARC 和发信域名验证。
- 通过安全方式提供 DirectMail 的最小权限凭证。

### 支付与财务

- 申请微信支付和支付宝企业商户，准备营业执照、法人证件、对公账户和经营场景材料。
- 确认课程商品类目、退款规则、发票流程和消费者投诉联系人。
- 提供商户号、应用 ID、API 证书或密钥；所有凭证仅通过密钥管理系统交付。
- 确认储值余额的会计、退款和资金合规边界；未完成专项审查前，正式环境不开放储值。

### 生成式 AI 与内容责任

- 与 Kimi 开放平台确认生产商用条款、并发额度、数据处理条款、已备案模型名称和备案号。
- 确认是否需要为 Academia 应用或功能履行生成式 AI/算法备案或登记，并咨询属地网信部门。
- 提供公开的投诉举报、安全和个人信息保护联系人。
- 决定是否允许未成年人使用；若未完成未成年人机制，首发应限制为 18 岁以上。

### 运营决策

- 确定退款、停课、内容下架、账号封禁和申诉政策。
- 确定每月模型与云资源预算、告警联系人和重大事故联系人。
- 确定首批真实课程、课程作者、版权来源和更新责任人。

## 由产品与工程推进

### 国内生产架构

- 将服务部署到阿里云 SAE，数据库迁移到 RDS PostgreSQL 高可用版。
- 完成 `PrismaAcademiaRepository`，执行 D1 到 PostgreSQL 迁移演练和校验报告。
- 使用 Tair 处理登录限流、会话撤销、支付幂等锁和短期任务状态。
- 使用 KMS/凭据管家保存模型、邮件和支付密钥；数据库只开放 VPC 私网访问。

### 完整账户系统

- 接入邮箱验证、找回密码、修改密码、修改邮箱和安全通知。
- 正式环境使用 Argon2id；支持密码参数升级和全局会话撤销。
- 提供账号数据导出、聊天记录删除、账号注销和保留期策略。
- 增加异常登录检测、审计日志、验证码和可配置封禁机制。

### 真实支付

- 实现微信支付与支付宝下单、签名、异步通知验签和退款。
- 支付状态以服务端 webhook 为准；所有回调幂等并保留可审计事件。
- 完成订单、权限、余额、退款和发票状态机测试；生产彻底关闭测试确认接口。

### 网络与数据安全

- 配置 TLS、WAF、DDoS 防护、CSP、安全响应头、上传扫描和接口限流。
- RDS 开启加密、自动备份和时间点恢复；完成恢复演练和最小权限审计。
- 接入 SLS/Sentry，建立可用性、错误率、模型费用、支付失败和安全事件告警。
- 完成依赖漏洞扫描、密钥轮换、渗透测试、灾备与应急预案。
- 配合专业机构确认网络安全等级保护定级、备案和测评范围。

### AI 安全与用户权利

- 在产品中公示模型提供方、模型名称、备案信息和 AI 生成标识。
- 建立输入输出安全策略、违规处置、申诉、投诉举报和审计留痕。
- 保持“学习教育工具”定位，不将 Agent 设计为情感依赖或人格替代服务。
- 提供聊天记录复制、删除、记忆关闭和单条遗忘；上线数据保留期限控制。

### 上线验收

- 完成并发、长连接、支付、数据迁移、备份恢复和灾难演练。
- 完成隐私政策、用户协议、AI 服务说明、未成年人政策和退款政策页面。
- 建立灰度、回滚、客服、值班和事故通报流程后，再开放真实支付。
